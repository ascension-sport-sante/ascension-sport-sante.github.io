# Ascension, coach sport-santé à domicile

Le site d'Ascension : coach sport-santé et enseignant en activité physique adaptée (APA-S), à domicile, à Paris 18e et en proche banlieue.

En ligne : https://ascension-sport-sante.github.io

- `index.html` : le site complet (une seule page, navigation par ancres).
- `fond/` : les paysages en vidéo du téléphone ; `sil/` : les silhouettes animées ; `sys/` : les illustrations des trois systèmes.
- Les demandes de bilan partent directement vers la feuille Google privée du coach : aucune donnée de client n'est enregistrée dans ce dépôt.
